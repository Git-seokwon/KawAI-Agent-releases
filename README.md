# KawAI-Agent

바탕화면에 사는 캐릭터 AI의 시험판 설치 파일을 두는 곳이에요. Windows 10·11 (64비트)용이에요.

## 설치

[Releases](https://github.com/Git-seokwon/KawAI-Agent-releases/releases)에서 가장 위 판의 `KawAIAgent-win-Setup.exe`를 받아 실행해요.
"Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]을 눌러요. 서명이 없는 시험판이라 떠요.
설치한 뒤에는 새 판을 앱이 알아서 받아요.

받기 전에 [이용 조건](이용%20조건.txt)을 읽어 주세요.
